PRODUTO

Uma operação comercial completa, não apenas um CRUD.

O OrderFlow conecta toda a jornada do cliente à rotina administrativa, aplicando regras de negócio no backend e mantendo rastreabilidade de cada alteração.

↯

CHECKOUT

Concorrência sem estoque negativo

O fluxo usa transação serializável, atualização condicional e restrição no PostgreSQL para preservar a última unidade mesmo sob requisições simultâneas.

orders.service.tsTypeScript
await prisma.$transaction(
  async (tx) => {
    const reserved = await tx.product.updateMany({
      where: { id, stock: { gte: quantity } },
      data: { stock: { decrement: quantity } }
    });

    if (reserved.count === 0) {
      throw new OutOfStockException();
    }
  },
  { isolationLevel: 'Serializable' }
);

ARQUITETURA

Separação clara entre interface, aplicação e dados.

O frontend Next.js utiliza uma rota proxy no mesmo domínio para conversar com a API NestJS, mantendo tokens em cookies protegidos. A camada de serviços concentra regras de negócio e o Prisma gerencia acesso transacional ao PostgreSQL.

  • Frontend: Next.js App Router + React 19
  • Backend: NestJS, DTOs, guards e Swagger
  • Persistência: Prisma ORM + PostgreSQL 17
  • Infraestrutura: Docker Compose, Railway e Vercel
