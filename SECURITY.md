# Política de segurança

Não publique vulnerabilidades em issues públicas. Envie um relato privado ao mantenedor do repositório com:

- descrição do problema;
- passos mínimos para reprodução;
- impacto esperado;
- versão ou commit afetado;
- possível correção, caso exista.

Nunca inclua senhas reais, tokens, dados pessoais ou chaves privadas no relato.
